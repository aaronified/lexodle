# Achievements

54 achievements with 216 levels in all, saved in your browser (nothing is sent anywhere). Every one has a medal:
**bronze**, **silver**, **gold** or **platinum**, and a family of them climbs in difficulty, from
the easy version to the platinum one.

Every level is counted: once the top level of a counting achievement (wins, games, languages, dailies and the like) is earned, it starts again from 0 and each round is counted, the medal staying; the best-of ones (fastest win, skill, luck, risk, bits) count each game that does what a level asks, and a streak counts each run that gets to a level. The number shows as ×N, and each repeat is shown as an unlock. The first win of each mode (and of the largest pool) is earned once, as are language mastery, the styles worn and the completionist. Each is earned once a language's number reaches its target (a best-of number, such as the best
skill, has no bar; a counting one shows how far you are). The page shows the medal on each,
filters by medal, and lists what you have earned: how many times (for the ones that can be done
again, such as a win in one guess), the first day and the latest.

They are earned per language ([Languages](Languages)), except the ones that count languages
(polyglot, mastery, completionist) and the learn ones, which are kept once for you whatever the
language ([Solver and learn mode](Solver-and-learn-mode)). Completionist does not ask for them.
Practice shows you the answer, so those count only what was well played: a word typed straight in
does not count. A learn achievement wears the flags of the languages you learned in.

**Full set** has four levels, one for each level of the achievements: level N is earned once level N of every other achievement has been earned, in whichever language has it furthest (the learn and language-count ones are kept once for you). It does not count itself.

**Completionist** is earned in a language by earning every one of that language's own achievements
(the ones that count languages and the mastery badges aside); it collects a badge for each language
completed, kept for good. **Tower of babel** (platinum) is earned once, when you are a completionist in every
language there is.

The page has an **all** filter beside the flags: every achievement then wears the flag of every
language played, bright where it was earned and dim where not, with the times added up.

**Language mastery** is one achievement with a badge for every language mastered: every length
the language offers, won at every tries level and every pool level it has the words for.
