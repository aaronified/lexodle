# Skill and luck in feedback-guessing games

`main.tex` is a working paper on the maths behind the **skill** and **luck**
scores in Lexodle's reviews. It is written to a submission standard but is **not
for submission**: it is here so that you, or someone better at maths, can check
it, tighten it and extend it.

## What it contains

- **Skill**: for a guess that splits the `N` words still possible into groups, the
  expected size of the pool you land in is `E = sum(size^2) / N`. Skill is
  `ln(N / E) / ln(N / E*)`, where `E*` is the smallest `E` any real guess achieves:
  0 for no split at all, 100 for the best real split. The logarithm (a ratio of
  Renyi order-2 entropies) keeps most guesses from crowding near 100.
- **Luck**: the chance of landing in a bigger pool less the chance of landing in a
  smaller one, strictly between -100% and +100%. It is a mid-distribution
  transform (Cliff's delta against a fresh copy), has mean exactly 0 for every
  guess, and its increments over a game are martingale differences, so luck is
  uncorrelated with skill and with itself.
- Why the two more obvious luck definitions fail (unbounded below, or biased), with
  explicit counterexamples.
- Extensions to the quartet and relay-race modes (log-weighted combination, head
  start), an exact algorithm and its cost, experiments on a real word list, a
  negative result on a capacity bound, and a list of open problems.

## Building

The paper uses standard packages only (`amsmath`, `amssymb`, `amsthm`, `booktabs`,
`tikz`, `geometry`, `hyperref`) and an inline bibliography. It has been compiled with
[Tectonic](https://tectonic-typesetting.github.io/) 0.17 (a single binary that fetches
packages on demand) and builds without errors:

```sh
tectonic main.tex
```

With a full TeX distribution, `pdflatex main.tex` twice also works. Without any LaTeX,
`python check_tex.py` is a static check (balanced braces and environments, every `\ref`
and `\cite` resolved, unescaped special characters).

## The experiments

Everything in the experiments section is reproducible from `experiments/` and reads
the word list the app ships (`app/assets/words/en.txt`). Python 3, no packages.

| Script | What it does | Saved output |
| --- | --- | --- |
| `first_guess.py` | exact `E` of every five-letter word as a first guess (about 2 minutes) | feeds the summary |
| `first_guess_summary.py` | best openings, skill of familiar ones, linear against logarithmic skill | `results/first_guess_summary.txt`, `results/first_guess.csv` |
| `luck_definitions.py` | three luck definitions compared on real first guesses | `results/luck_definitions.txt` |
| `capacity_bound.py` | the negative result on bounds for the best conceivable split | `results/capacity_bound.txt` |
| `prior_bias.py` | how far the game's frequency-weighted answer draw moves the mean luck from zero | `results/prior_bias.txt` |
| `risk_attitude.py` | four valuations of a split (worst case, collision, Shannon, group count) played out over 1,000 games | `results/risk_attitude.txt` |
| `reduction_accounting.py` | skill + risk + luck = total reduction, checked on real guesses | `results/reduction_accounting.txt` |
| `worked_game.py` | one real game (caret, least, agent) priced in skill, risk and luck | `results/worked_game.txt` |
| `play_skill.py` | log skill of a strong and a casual simulated player, for calibrating thresholds (a few minutes) | `results/play_skill.txt` |
| `verify_theorems.py` | numerical checks of the theorems, independent of the app (about a minute) | `results/verify_theorems.txt` |

`common.py` holds the feedback rule (the same as the game's), the group sizes, `E`,
skill and luck.

## The implementation

The app computes the same quantities in `app/lib/logic.dart` (`scoreGuess`,
`chanceLuck`, `skillAgainst`, `analyseGuesses`) and `app/lib/multi_analysis.dart`
(`analyseMulti`). The properties in the paper are tested in
`app/test/logic_test.dart`, `review_plots_test.dart` and `multi_analysis_test.dart`
(bounds, zero mean over random partitions, the last-try rule).
