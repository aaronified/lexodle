# Word list sources

Candidates come from [wordfreq](https://github.com/rspeer/wordfreq) (CC BY-SA 4.0). Each is kept only if the language's Hunspell dictionary accepts it; only the filtered word lists are shipped, not the dictionaries. The licence is the one each dictionary package states for its dictionary and affix files.
