## Data Requirements

### lexodle_list.csv

The game requires a CSV file containing the word list with the following columns:

- `word` — the word itself (string)
- `lettercount` — number of letters in the word (integer)
- `wordcount` — frequency count from Google Ngrams (integer)
- `bookcount` — number of books the word appears in (integer)
- `meanings` — dictionary definitions (JSON string)
- `phonetics` — pronunciation information (JSON string)
- `audio` — relative path to the pronunciation audio file (string)
- `sourceUrls` — links to Wiktionary entries (array of strings)

The `sourceUrls` column is included for future functionality even though it is not currently used by the game.

### dictionary_audio/

Directory containing `.mp3` pronunciation audio files. The `audio` column in `lexodle_list.csv` provides the relative path to each word's audio file (e.g., `./dictionary_audio/aback.mp3`).

## Scripts

### lexodle.py

Full-featured GUI Lexodle game with word definitions and audio.

**Inputs:**
- `./lexodle_list.csv` — word list with metadata
- `./dictionary_audio/` — pronunciation audio files

**Features:**
- Customizable word length and attempts via Settings menu
- Weighted random word selection (based on word frequency)
- Standard Lexodle coloring: green (correct position), yellow (wrong position), red (not in word)
- Displays word info: phonetics, definitions, synonyms, antonyms
- Plays pronunciation audio
- Links to Merriam-Webster dictionary
- Shows eligible word count after each guess

### lexodle_simulator.py

Simplified Lexodle game (no dictionary metadata).

**Inputs:** `./lexodle_list.csv`

**Features:**
- Basic Tkinter GUI
- Uniform random word selection
- Standard Lexodle coloring

### lexodle_solver.py

CLI tool to help solve Lexodle puzzles.

**Inputs:** `./lexodle_list.csv`

**Functions:**
- `filter_words_by_absent_letters()` — exclude words with certain letters
- `filter_words_by_present_letters_and_positions()` — filter by required letters and position patterns

### solver_gui.py

GUI puzzle solver with entropy-based recommendation.

**Inputs:** `./lexodle_list.csv`

**Features:**
- Enter guess + feedback (G=Green, Y=Yellow, X=Gray)
- Recommends best next guess using entropy scoring
- Shows possible words remaining
- Settings menu for word length

### top_guesser.py

Finds minimum set of words covering all 26 letters.

**Inputs:** `./lexodle_list.csv`

**Output:** Minimum word set that covers n unique characters

Uses branch and bound algorithm with heuristic pruning.

## Setup

1. Obtain `lexodle_list.csv` and the `dictionary_audio/` folder (see Data Requirements)
2. Run `python lexodle.py` to play
3. Run `python solver_gui.py` to use the solver

## Notes

- The `lexodle_list.csv` and `dictionary_audio/` folder are required to run the game. These are generated by a separate data pipeline project.
- Wiktionary links are included in the data for future functionality but are not currently used by the game.
- The game requires ffmpeg for audio playback (configured in `lexodle.py`).
- Configuration is stored in `config.json` — controls default word length, attempts, and dictionary file pattern.
